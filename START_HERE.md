## 🎯 WHAT YOU NEED TO DO (5 STEPS - 15 MINUTES)

### **Step 1: Create GitHub Repo (2 min)**
```
1. Go to https://github.com/new
2. Name: rag-knowledge-chatbot
3. Description: AI HR Policy Assistant using RAG
4. Make it PUBLIC
5. Create repository
```

### **Step 2: Push Code (2 min)**
```powershell
cd "C:\AI Projects\RAG Knowledge Chatbot"
git remote add origin https://github.com/YOUR_USERNAME/rag-knowledge-chatbot.git
git branch -M main
git push -u origin main
```
⚠️ Replace `YOUR_USERNAME` with your GitHub username!

### **Step 3: Deploy Frontend (5 min)**
```
1. Go to https://vercel.com/sign-up
2. Sign up with GitHub
3. Click "Add New Project"
4. Select rag-knowledge-chatbot repo
5. Set Root Directory to: web-app
6. Click Deploy
7. Wait for "✓ Deployment Successful"
8. Copy your URL
```

### **Step 4: Deploy Backend (5 min)**
```
1. Go to https://railway.app
2. Sign up with GitHub
3. New Project → Deploy from GitHub
4. Select rag-knowledge-chatbot
5. Click Deploy
6. Wait for build complete
7. Copy your URL
```

### **Step 5: Connect Them (1 min)**
```
1. Go to Vercel Dashboard
2. Click your project
3. Settings → Environment Variables
4. Add: REACT_APP_API_URL = [YOUR RAILWAY URL]
5. Go to Deployments
6. Click latest → Redeploy
7. Wait for success
```
